# PhiClient UI 设计规范文档

> 本文档汇总了目前确认的所有 UI 设计规范与各页面结构。后续开发请严格遵循此文档中的几何约束、颜色体系与交互逻辑。

---

## 一、 全局设计规范

### 1. 核心形状：右偏平行四边形
- **形状定义**：邻角分别为 **75° / 105°**，上底相较于下底向右偏移。
- **边角**：**全局绝对无圆角**，所有斜切方向全局固定（不镜像）。
- **尺寸偏移**：高度为 `h` 时，上底右移量严格为 `h / tan(75°) ≈ 0.268h`。小尺寸组件也**不允许**压缩偏移。
- **应用范围**：所有卡片、按钮、面板容器、**文本输入框（含内部编辑区）、滑块（含手柄）、滚动条（含滑块）**全部强制同形。内部文字排版可保持矩形阅读流。

### 2. 颜色与视觉体系
- **无描边原则（定稿）**：全局默认与交互状态**绝不使用描边**。所有边界、焦点、选中、悬停状态，全部通过**底色差**与**文字/图标颜色变化**来区分。
- **深色主题底色层级（L0-L5）**：
  - `L0` (`#0E0F12`)：游戏遮罩/最深底/深黑选中态。
  - `L1` (`#16181D`)：PhiHub 窗口底。
  - `L2` (`#1D2027`)：导航栏底、主内容区底。
  - `L3` (`#262A33`)：卡片/控件默认底。
  - `L4` (`#313641`)：悬停底。
  - `L5` (`#3E4553`)：选中/强调底/白底替代。
- **文字与强调色**：
  - 主文字：`#E8EAED`
  - 次文字：`#A0A6B0`
  - 主题强调色：青蓝色 `#4FD1C5`（用于进度条、选中图标、开关指示块等）。
- **浅色主题预留**：结构不变，L0-L5 明度阶梯反转（如 L0 变纯白，文字变深色），依旧无描边。

### 3. 适配与动效
- **设计基准**：1920×1080 分辨率，GUI Scale 2。导航项高度基准 48px，图标 20px，全部按 GUI Scale 等比缩放。
- **无滚动条原则**：所有列表（导航栏、模组列表等）均不显示可见滚动条，支持鼠标滚轮/触控板滑动，不占位。
- **惯性回弹**：列表滚动带惯性（衰减系数 0.92），边界带橡皮筋回弹效果。

## 二、 PhiHub 主窗口架构

### 1. 尺寸与自适应
- **外接矩形比例**：将平行四边形两侧补全后，外接长方形严格为 **16:9**。
- **面积占比**：PhiHub 平行四边形自身面积约占游戏窗口面积的 **50%**。
- **自适应行为**：不可手动拖拽改变大小，仅随游戏窗口自适应（0.15s 平滑过渡），始终居中且完整显示。
- **面积适配公式**：
  - `Ws`、`Hs` 为窗口宽高，`As = Ws × Hs`
  - 面积比常数 `r = 1 - (9/16) × cot(75°) ≈ 0.84928`
  - 目标外接矩形宽 `W_target = sqrt( 8 × As / (9r) )`
  - 目标外接矩形高 `H_target = 9 × W_target / 16`
  - 实际取 `W_actual = min( W_target, Ws, (16/9) × Hs )`，并居中放置。

### 2. 布局结构
- **左侧**：主内容区（外壳同形）。
- **右侧**：导航栏斜带。

## 三、 导航栏与交互

### 1. 导航栏布局
- **位置与宽度**：位于右侧，从 PhiHub **右侧斜边向内**水平测量 `10% × W` 的宽度，形成一条斜带。
- **容器样式**：不单独绘制同形外轮廓，靠底色差（L2）与主内容区区分。
- **导航项**：统一竖直左边界排列；宽度随所在高度斜带自适应；图标水平垂直居中。
- **当前列表**：`Home` / `Module` / `Music` / `Setting` / `HUD`。

### 2. 导航项状态与交互
- 仅显示图标；默认透明（L2），悬停（L4），选中（L5 + 图标变强调色），按下短促反馈（0.08s）。
- **无禁用态**：未开放功能直接隐藏导航项，不展示灰置状态。

### 3. 悬浮提示 (Tooltip)
- **触发与动效**：悬停 0.2s 后出现，上浮 6px + 淡入（0.15s ease-out）；移出 0.2s 后反向消失。
- **位置策略**：默认图标上方；若上方超出游戏窗口顶部，改为浮现在图标**右侧**（垂直居中）。
- **边界**：提示框为同形，允许超出 PhiHub 外框，允许覆盖主内容区，但**绝不可超出游戏窗口**。

## 四、 页面功能设计

### 1. Home 页（个人主页）
- **玩家主信息卡**（同形）：支持自定义背景图 + 60% 深色遮罩。
  - 左侧：同形头像、大号 ID。
  - 右侧：实时当前日期时间（大号数字）。
  - 下方：玩家简介（次文字色）。
- **底部音乐控制区**（同形卡片，L2/L3 底）：
  - 左侧：小封面 + 歌名/艺术家信息。
  - 中部：上一首 / 播放暂停 / 下一首（同形按钮），下方配同形音乐进度条（已播放为强调色，未播放 L4）。
  - 右侧：**GitHub 图标按钮**（同形，L3 底），点击跳转项目仓库。

### 2. Module 页（模组管理）
- **左侧：中心聚焦列表（拨盘式）**：
  - 点击任意模组，平滑滑动至垂直中心（0.2s ease-out）。
  - 停止滚动时自动吸附最近项至中心。
  - 选中项（中心）深黑（L0）底 + 主文字 + 简介；右侧延伸出一个白底（L5）小平行四边形作为“更多设置”按钮。
  - 上下边缘使用透明到背景色的渐变遮罩，让未选中项自然淡出。
- **右侧：详情面板**：
  - 顶部大卡片（L3/L4）：居中显示模组图标。
  - 中部小卡片：纯视觉装饰条。
  - 右下角：同形开关按钮（控制模组启用/禁用）。

### 3. Music 页（音乐模块）
- **顶部**：大标题 “Music”，右侧配同形搜索框（L3 底，Search 占位）。
- **分类栏**：同形标签页（如 All / Favorite），选中（L5/强调色），未选中（L2/L3）。
- **中间列表**：歌曲同形卡片（L2/L3 底，包含封面、歌名、歌手等）。
- **底部控制栏**：固定于主内容区下方。
  - 左侧当前播放信息，中部上一首/播放/下一首，右侧音量滑块及添加歌曲按钮。
  - 全部组件同形，无描边。

### 4. Setting 页（设置）
- 纵向排列的同形卡片（L3 底）。
- **主题设置**：同形滑块开关（Toggle）。
- **语言设置**：同形下拉按钮（附带下拉浮层）。

### 5. HUD 布局编辑（简版归档）
- 点击导航项 `HUD` 后，PhiHub 整体平滑淡出并隐去，全屏显示游戏画面（带模糊/深色遮罩）。
- 仅显示当前已开启模块的 HUD 控件，控件使用同形外壳。
- 提供极简控制条用于保存退出、重置和网格吸附开关，支持拖拽定位。
